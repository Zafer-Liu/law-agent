# 法晓 · AI 法律助手

> 2026 中国（广西）—东盟"AI+法律"应用创新大赛 · 高校学生赛道 · 法治宣传方向

一个面向公众的 AI 普法应用，围绕"把一个法律问题，转化为有依据、可理解、可练习的学习路径"构建：

1. **法律问答** — 面向普通人处理民事、合同与刑事问题的 RAG 引用式问答；每个回答标注可核对的引用，并展示每条依据的效力状态（现行有效 / 已被修改 / 废止失效 / 未确认）、公布与施行信息；支持多轮对话、历史管理（重命名 / 置顶 / 分类 / 导出 Markdown）与"有帮助 / 没帮助"反馈；对话可一键脱敏整理成事项档案
2. **问题工作台** — 把一个法律问题转化为可执行的处理路径：结构化采集案情（事件、当事人关系、金额、证据、诉求、期限风险），检索现行法条后生成事项档案——问题归类、事实摘要、适用依据、仍需补充的信息、证据清单、行动清单、风险提醒，并推荐可以练手的模拟庭审；知识库已下架废止与已被修改的法条文本，检索只引现行来源
3. **沉浸模拟法庭** — 法庭式布局的多智能体庭审对抗（审判长 ⇄ 公诉人 ⇄ 辩护人 ⇄ 被告人）。用户可作为旁听观众观看全程，或选择人民陪审员、公诉人、辩护人、被告人：陪审员进行预判和发问，诉讼角色在两个关键节点从预设意见或自定义内容中完成发言；庭审支持暂停，最后可作出裁判预测并附裁判说理——系统对照真实判决按证据判断、程序理解、说理完整性三维评分；判决与复盘页内置知识复习卡片，可把本案法条标记为已掌握/待复习；问答回答完成后会推荐可练手的同类模拟案件，一键进入法庭
4. **獬豸桌宠与学习地图** — 3D 桌面宠物伴随学习成长：完成带依据的问答和庭审积累经验、解锁阶段形态；首次掌握一个法条知识点获得额外经验；可主动授权记录咨询摘要，形成个性化记忆。"学习地图"把知识点、事项档案与庭审记录按主题（刑事、劳动、婚姻家庭、消费等）聚合成导航：掌握进度、待复习法条、可练手的案例轨道一目了然
5. **账户体系** — 注册 / 登录、数据按账户隔离（匿名期数据登录后自动并入）、修改密码、全部数据导出（JSON）、注销账号并删除全部数据；首个注册用户自动成为管理员，可管理知识库上传、检索增强开关、运行日志、回答反馈与产品事件统计；认证接口按 IP 限流

## 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env   # 编辑 .env 填入模型配置
python -m legalweb
```

打开 http://127.0.0.1:5000

## 配置

| 环境变量 | 说明 |
|---|---|
| `LAW_LLM_BASE_URL` | OpenAI 兼容接口地址（以 /v1 结尾） |
| `LAW_LLM_API_KEY` | API Key |
| `LAW_LLM_MODEL` | 法律问答模型，默认 `MiniMax-M3` |
| `LAW_COURT_LLM_BASE_URL` | 模拟法庭的 OpenAI 兼容接口地址 |
| `LAW_COURT_LLM_API_KEY` | 模拟法庭 API Key |
| `LAW_COURT_LLM_MODEL` | 模拟法庭模型，默认 `MiniMax-M2.7-highspeed` |
| `LAW_EMBED_BASE_URL` | （可选）向量服务地址，配置后启用语义检索 |
| `LAW_EMBED_API_KEY` | （可选）向量服务 Key |
| `LAW_PKULAW_TOKEN` | （可选）北大法宝 MCP 检索 Token，配置后问答启用在线法条检索（条目附原文链接与时效性） |
| `TYPESAFE_API_KEY` | （可选）TypeSafe API Key，配置后启用 Jev 检索质量门控 |
| `LAW_JEV_GATE` | Jev 开关，默认 `1`；设为 `0` 可关闭 |

未配置向量服务时自动降级为词法 + FTS5 检索，界面会明确标注。

## 技术架构

- **后端**：Flask + SQLite/FTS5 + jieba 词法检索 + 可选向量（RRF 融合）+ 可选 Jev 相关度/提示注入门控
- **前端**：原生 HTML/JS/CSS，零构建步骤
- **LLM**：OpenAI 兼容接口，支持备用模型自动切换
- **模拟法庭**：多 Agent 编排（公诉人/辩护人/被告人/书记员），程序状态机保证庭审流程合法性，封闭卷宗接地防幻觉；旁听角色不打断流程，其他角色在「法庭调查后」「法庭辩论后」进入相应检查点，通过 `/continue` 续跑；前端可暂停事件播放并保留当前发言，评议复盘含用户判断轨迹

## 目录结构

```
legalweb/          # Python 后端包
  app.py           # Flask 路由 + SSE（问答/庭审/账户/反馈/埋点）
  database.py      # SQLite schema 与幂等迁移
  rag.py           # 检索引擎（词法 + FTS + 向量 RRF）
  llm.py           # OpenAI 兼容客户端
  qa.py            # 法律问答（RAG + 引用校验）
  source_meta.py   # 法条效力元数据解析（时效性/公布/施行）
  courtroom/       # 模拟法庭
    cases.py       # 从内置资产加载并校验模拟法庭案例
    agents.py      # 角色卡（公诉人/辩护人/被告人/书记员）
    engine.py      # 庭审状态机 + SSE 事件流
assset/
  law/             # 法律问答内置法条
  case/            # 法律问答内置判例
  moot-court/      # 模拟法庭案例 JSON
web/               # 前端（原生 HTML/JS/CSS）
tests/             # 自动化回归测试（账户隔离/问答/庭审/宠物/反馈埋点）
seed/              # 种子法律知识库（法条节选）
```
